# WolfeConnect Agent Toolkit

Portable, model-neutral agent standards, skills, plugin manifests, scripts,
templates, and validation fixtures.

This is not a household configuration repository and not a personal memory
store. The private `WolfeConnect/homelab` and `WolfeConnect/stella-soul-stone`
repositories remain the sources for operational reality and private agent
continuity.
