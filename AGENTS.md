# Agent Toolkit Contribution Rules

This repository is public and portable. It contains model-neutral standards,
skills, plugin manifests, scripts, templates, tests, and catalog metadata.

Never add household topology, personal continuity, private prompts, secrets,
credentials, production endpoints, customer material, or generated runtime
state. Work-derived candidates require an explicit manual exception record
before publication.

Every reusable asset must declare its purpose, compatibility, provenance,
validation method, and removal or replacement path in `catalog/registry.yaml`.
